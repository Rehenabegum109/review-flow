# ReviewFlow — Project Submission & Review Platform

ReviewFlow is a web application designed to help students submit projects, mentors review submissions, and administrators manage the platform through role-based dashboards.

## Features

- Role-based access for Students, Mentors, and Admins
- JWT authentication with cookie-based authentication
- Project submission and review workflows
- Mentor feedback and submission status management
- Admin dashboard for platform management
- Responsive user interface
- Light and dark mode support

## Getting Started

### Prerequisites

- Node.js
- npm
- PostgreSQL database
- Configured backend environment variables

### Installation

Clone the frontend repository:

```bash
git clone YOUR_FRONTEND_REPOSITORY_URL
cd YOUR_FRONTEND_FOLDER
npm install
```

Create a `.env.local` file:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
```

Make sure the backend is running and the API URL matches your configuration.

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
